FAQ

How does the engine handle hardware failures?
The engine uses health checks, automatic failover, and state replication across nodes so workloads can continue while an affected node is isolated.
Is on-premise deployment supported?
Yes. Fully air-gapped, containerized, and private cloud installs are available for teams with strict security or compliance requirements.
What data sources can we connect?
Telemetry streams, sensor logs, event queues, databases, and internal APIs can be connected through the platform SDK.
How do teams monitor production systems?
Dashboards expose execution traces, node health, retries, latency, and failover events with alerting hooks for your existing tools.
Can we define safety constraints?
Yes. You can configure policy gates, fallback paths, approval thresholds, and hard limits for critical autonomous actions.
How long does implementation take?
Most teams start with a focused pilot in a few days, then expand into production after validating reliability, observability, and integration needs.
